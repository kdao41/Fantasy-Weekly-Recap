# League data

Saved history for the leagues shown in `index.html` (the Almanac) and `history.html`. Everything here is
generated by the scripts in `scripts/`; the only hand-edited files are `leagues.json` and the
`real_name` fields in `managers.json`.

## Which folder to read

| You want | Read | README |
|---|---|---|
| A league's whole history, one record per person across platforms | `combined/<league>/` | [combined/README.md](combined/README.md) |
| Lineups, player points, transactions, scoring rules, anything not summarized | the raw archives below | |
| Yahoo years only (2015 to 2022 Aggtown, 2019 to 2023 Nooblets) | `yahoo/<league>/` | [yahoo/README.md](yahoo/README.md) |
| Sleeper years only (2023 on Aggtown, 2024 on Sober Gang) | `sleeper/<league>/` | [sleeper/README.md](sleeper/README.md) |

**Start with `combined/`** unless you need detail it doesn't carry; its README lists exactly what
is left out and where to find it.

## Leagues

`leagues.json` is the map between platforms:

| id | League | Yahoo years (folder) | Sleeper years | Combined |
|---|---|---|---|---|
| `aggtown` | Aggtown FFL | 2015 to 2022 (`yahoo/aggtown`) | 2023 to 2025 | 11 seasons |
| `sobergang` | Sober Gang | 2019 to 2023, as "Nooblets" (`yahoo/nooblets`) | 2024 to 2025 | 7 seasons |

Each entry's `people` maps a Sleeper display name to that person's Yahoo nickname. That is how
one person's Yahoo and Sleeper seasons become one career. A Sleeper manager missing from `people`
(for example Aggtown's `bAnmly`, who only played 2024) is simply a separate, Sleeper-only manager.

The season in progress is never saved here; the Almanac reads it live from Sleeper.

## Folder layout

```
data/
  leagues.json               league map (hand-edited)
  yahoo/<league>/            Yahoo seasons: summaries + raw/<season>.json + raw/yahoo_api/ (XML archive)
  sleeper/<league>/          Sleeper seasons: summaries + raw/<season>.json + raw/sleeper_api/ (JSON archive)
  sleeper/players_nfl.json   Sleeper's player directory (shared by both Sleeper leagues)
  combined/<league>/         Yahoo + Sleeper summaries (no raw/ of its own)
```

Every summary folder (`yahoo/*`, `sleeper/*`, `combined/*`) has the same files in the same
format: `league_history`, `manager_season_records`, `manager_career_records`,
`all_weekly_scores`, `weekly_standings`, `weekly_highlights`, `managers.json`, and
`seasons/<year>/` with `season.json`, standings, records, draft and `weeks/week-NN.json`. The
field-by-field reference is [yahoo/aggtown/README.md](yahoo/aggtown/README.md#file-reference);
it applies to all of them.

## Pipeline

```
Yahoo website session --scripts/yahoo_scrape.py fetch/archive--> yahoo/<league>/raw/
Sleeper public API ----scripts/sleeper_export.py fetch---------> sleeper/<league>/raw/
both raw/<season>.json --scripts/league_build.py (shared)-------> every summary folder
yahoo raw + sleeper raw + leagues.json --sleeper_export.py combine--> combined/<league>/
```

`raw/<season>.json` is the platform-neutral season format; `league_build.py` turns any list of
them into the summary files, so Yahoo and Sleeper seasons build identically.

## Regenerating

From the repo root:

```
python3 scripts/sleeper_export.py all                          # Sleeper fetch + combine, every league (no login)
python3 scripts/sleeper_export.py combine aggtown              # rebuild one combined league after editing names
uv run --python 3.12 scripts/yahoo_scrape.py build aggtown     # rebuild Yahoo summaries from raw/, offline
uv run --python 3.12 scripts/yahoo_scrape.py fetch nooblets    # re-download Yahoo (needs the browser login)
```

After a Sleeper season finishes, `sleeper_export.py all` adds it to `sleeper/` and `combined/`.

## Things that trip people up

- **Names:** every `manager` value is a display label (latest nickname, or "Nickname (Real Name)").
  It is the join key within one folder, but labels differ between `yahoo/`, `sleeper/` and
  `combined/` for the same person. Join across folders through `managers.json` ids, never labels.
- **Scoring changed over time:** passing TD was 5 points through 2021 in Aggtown and 4 after;
  Aggtown playoffs went from 8 teams to 6 in 2022. Compare records freely, points loosely.
- **Opening pages from disk:** the HTML pages fetch these files, so they need a local server
  (`python3 -m http.server`) or GitHub Pages, not a `file://` URL.
